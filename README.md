# FUTURE_ML_03 - Resume Screening System

## 📌 Project Overview

This project is a Machine Learning-based Resume Screening System developed as part of the Future Interns Machine Learning Internship.

The system analyzes resumes and matches them with a given job description. It calculates a similarity score, ranks candidates, and identifies missing skills.

## 🎯 Objectives

- Clean and preprocess resume data
- Analyze resume categories and experience
- Match resumes with job requirements
- Calculate candidate match scores
- Rank candidates
- Identify skill gaps
- Visualize the results

## 📂 Dataset

The dataset contains resume information including:

- Resume ID
- Resume Category
- Resume Text
- Skills
- Experience Years

Total resumes used: **2,834**

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Google Colab
